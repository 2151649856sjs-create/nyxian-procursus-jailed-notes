# 01 · 侧载与证书

这一篇解决两件事：**把 Nyxian 装上去**，和**给它一张能用的签名证书**。
第二件事比第一件容易漏，而且漏了就卡在后面所有步骤。

> 验证环境：iPhone 11 / iOS 27.0 Beta 1 (`24A5355q`) / 免费 Apple ID / Nyxian `0.11.5 (20261012.26.RELEASE)`

---

## 一、侧载 Nyxian

### 官方要求

官方 Installation Guide 写得很明确：

- **系统**：iOS / iPadOS 16+
- **侧载工具**：**AltStore 2.0+ 或 SideStore 0.6.0+**
- **账号**：免费或付费 Apple 开发者账号
- ⚠️ **不能用 LiveContainer 运行**（原文：`It will not work in LiveContainer!`）
- ⚠️ **安装时不要丢掉任何扩展**（原文：`Do not forget to keep all extensions when installing!`）

> **实测备注**：本文用的是 **iLoader（iloader）**，它**不在**官方支持列表里，但侧载流程本身是成功的
> （登录 → 注册开发设备 → 取证书与描述文件 → `App signed!` → 安装）。如果你卡在侧载环节，
> 优先换上官方明确支持的 AltStore / SideStore 再试。

### 步骤

1. 用你的侧载工具正常安装 Nyxian 的 IPA。
2. 装完在 iOS 设置里信任该开发者（设置 → 通用 → VPN 与设备管理）。
3. 打开 Nyxian 确认能进主界面。

---

## 二、导出开发者证书（`.p12`）

Nyxian 需要一张**你自己的** `.p12`，用来给**你自己编译出来的 App** 签名。
官方文档给的方法是：从你安装 Nyxian 用的那个商店里导出。

### 步骤

1. 打开你用来装 Nyxian 的那个商店（SideStore / AltStore）。
2. 进它的 **设置** 页，拉到最下面。
3. 点 **`Export Signing Certificate...`**（有些版本写作 `Certificate Management` → `Export Signing Certificate...`）。
4. 系统会让你**设一个密码** —— **记住它**，下面导入时要输同一个。
5. 保存到设备（存进「文件」App，位置随便，比如「下载」或「我的 iPhone」）。

### 怎么确认导出的是能用的那张

在商店的证书页里，每张证书会显示几个关键字段。**只有同时满足下面两条的才有用**：

| 字段 | 要看的 |
|---|---|
| `Keys` | 必须是 **`public + private`**。只写 `public` 的说明私钥不在里面，导出来也签不了名。 |
| 状态 | 必须是**有效**（绿色；并且它应该出现在 `Active Local Certificate` 那一栏）。 |

页面上 `(R)` 后缀表示该证书在 Apple 开发者门户上是远程注册的。
列表底部通常还有一行说明，原文大意是"Suffix (R) indicates the certificate is registered
remotely on Apple's developer portal"。

> **关于有效期**：证书本身有效期是 **1 年**（实测到 2027-10-03）。
> 而**免费账号签出来的 App 只能撑 7 天**，到点要重新签一次 —— 但**证书不用重做**。
> 这两件事很多人会搞混。

## 三、把证书导入 Nyxian

1. 打开 Nyxian。
2. 首次运行时，如果没证书，会弹 **`Signing Isn't Set Up`**：

   > Nyxian needs a signing certificate to install and launch the apps you build.
   > Without one you can still write and compile code, but you won't be able to run it on this device.

   点 **`Set Up Signing`**。

3. 弹出一个 **`Set Up Signing`** 表单，两项：
   - **`Select Certificate`** —— `PKCS#12 certificate (.p12 or .pfx)`，点它打开**系统文件选择器**
   - **`Password`** —— 输密码
4. 选你刚才导出的那个 `.p12`，输密码，点 **`Import`**。

### 验证

弹窗不再出现，就说明成了。表单里的说明文字也确认了它的用途边界：

> The password and certificate is only used to sign apps on your behalf, they stay entirely on your device.

### 怎么把 `.p12` 弄到手机上（Windows 没有 AirDrop）

最省事的路子：用微信或 QQ 的**文件传输助手**发给自己，手机上点开 → 「存储到文件」→ 存进「文件」App。

> ⚠️ 一定要用「**文件**」方式发送，不要用"图片/视频"，那会被压缩，证书就废了。
> 文件很小（3 KB 左右），传起来没压力。

## 四、常见坑

| 现象 | 原因 / 处理 |
|---|---|
| 证书页里那张是**红色**的 | 失效了，别选它 |
| 证书 `Keys` 只有 `public` | 私钥不在，导出来签不了名，别选它 |
| 导入后还弹 `Signing Isn't Set Up` | 没导对，或者密码输了；重来一次 |
| 7 天后 App 打不开 | 免费账号的正常现象，用 SideStore 重新刷新签名即可，**证书不用重导** |
| `Installed Root Certificate Authorities` 点不开 | 已知异常，原因未确认。见 [99-未解决.md](99-未解决.md) |
