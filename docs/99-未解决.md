## 二、已经排除掉的方向（别重复走了）

排查过程中确认**不是**原因的，记在这儿省时间：

| 被怀疑的 | 为什么排除 |
|---|---|
| **bootstrap 服务器的问题** | 直接拉 `https://nyxian.app/bootstrap/org.emexlabs.rootca.v1.pub.nxt2c`：HTTP 200、119 字节、`Content-Type: application/octet-stream`，SHA-256 与本地文件逐字节一致 |
| **那个 `.nxt2c` 文件损坏** | 逐字节解析通过，曲线点代入 P-256 方程验证在曲线上 |
| **域名不对** | `emexlabs.org` 与 `nyxian.app` 是同一个站点、同一张证书（Let's Encrypt，中间证书 `YE2`，有效期到 2027-01-13） |
| **TLS / 证书链** | 内层 App 的 Info.plist 里写着 `NSAppTransportSecurity = { NSAllowsArbitraryLoads: True, NSAllowsLocalNetworking: True }`，ATS 是**关掉的**，不可能是策略拦截 |
| **侧载工具登录/签名环节** | 侧载日志显示登录、注册设备、取到证书与描述文件、`App signed!`、安装完成，全部成功 |
| **"证书没装"导致 bootstrap 失败** | 这是两件独立的事：签名未设置会弹 `Signing Isn't Set Up`（这是给"你自己编译的 App"签名的），和 bootstrap 下载是两个环节 |
| **ROM 包结构不对** | 包内 155 个条目全在 `ROM/` 顶层目录下，`ROM/manifest.plist` 在最上。**实测刷写器能直接吃这个结构**，不需要剥掉 `ROM/` 这层 |
| **启动图卡住 = 卡死** | 那是 ROM 自己的启动图（`bootl.jpg`，白底深灰桌子），而且它是**引导器画的**。所以"图在闪"只说明引导器界面线程活着，**不代表 ROM 有进展**。实测靠"再重启一次"就过去了 |

## 三、几个容易误判的点（提前说，省得你也踩）

1. **`下载失败` 可能其实是"写入失败"。**
   引导器的 `downloadFile()` 返回的是 `writeToFile:atomically:` 的结果。
   屏幕上的 `downloading "..." failed` 不能直接理解成网络问题。

2. **首启真的很慢，别急着杀。**
   ROM 里 `bootstrap.tar.zst` 是 25 MB、约 6670 个文件，首次启动要全部铺进虚拟根。
   **但"重启一次"往往就能过** —— 实测就是这样。

3. **装包期间的卡和烫是正常的。**
   装包 = 解压 + 大量写文件 + 可能重签。再叠加 syscall 转发和没 JIT。
   **别在装包的中途按"取消下载"**。

4. **`Obfuscate Log` 开着的时候日志是读不了的。**
   要拿日志先去 `Boot Configuration` 关掉它。而且**改了要重启才生效**。

5. **免费账号 7 天要重签一次。**
   App 打不开的时候先想这个，别以为是环境坏了。**证书本身是 1 年，不用重做。**
